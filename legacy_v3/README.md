# Archived: v3 / 4.0 lineage

This folder holds the code and documentation from the earlier releases (v3.0 and the 4.0 API and dashboard work), kept unchanged so the history stays auditable. The original README is [`README_v3.md`](README_v3.md).

**Do not use it for scientific results.** It was built on the *S. cerevisiae* S288C reference in place of the strain genome, an incorrect gene-loss list, a mis-attributed toxin A activity and a convolutional surrogate that the data did not justify. Release 5.0.0 at the repository root replaces it. [`../ERRATA_v3_to_v4.md`](../ERRATA_v3_to_v4.md) lists every claim that changed.

The hosted demo on the GCP instance still serves this build until it is redeployed.
